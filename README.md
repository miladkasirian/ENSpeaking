# EN Speaking

A small web app for practicing spoken English with an AI partner, made for iPhone (Safari) and also usable on a computer.

- **Conversation**: speak, see exactly what was heard, get corrections, hear a reply.
- **Repeat after me**: the app says a sentence, you repeat it, and missed words are marked.

How it works: your voice is recorded in the browser, sent to OpenAI speech-to-text, then to a chat model, and the reply is read by the iPhone voice (free) or an OpenAI voice.

The OpenAI API key is typed into Settings on each device and stored only in that browser. It is never part of this repository.

Live: https://miladkasirian.github.io/ENSpeaking/
