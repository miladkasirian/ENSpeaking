# EN Speaking

A web app for practicing spoken English with an AI partner. Made for iPhone (Safari, add it to the Home Screen) and works on a computer too.

- **Conversation**: speak or type. You see exactly what was heard, the corrections, and a spoken reply. The chat is kept on the device until you delete it.
- **Repeat after me**: the app says a sentence, you repeat it, missed words turn red.
- **Three engines**: Turn by turn (speech to text, chat model, voice; OpenAI or Gemini models), OpenAI Realtime (a live voice call), or Gemini Live (a live voice call, free on a free-tier Gemini key).
- **Model choice** for the chat, speech-to-text and realtime models.
- **Live cost counter** for the session and an all-time total on the device, from OpenAI's published prices (editable in Settings).

The OpenAI and Gemini API keys are entered in Settings on each device and stored only in that browser. It is never part of this repository.

Live: https://miladkasirian.github.io/ENSpeaking/
